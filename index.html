RCI TOOLS
Open RCI Tools

iPhone — add the icon to your home screen

  1. Open this page in Safari
  2. Tap the Share button (square with arrow)
  3. Tap Add to Home Screen, then Add

Android — add the icon to your home screen

  1. Open this page in Chrome
  2. Tap the ⋮ menu (top right)
  3. Tap Add to Home screen (or Install app), then Add

Computer — add the icon to your desktop

  1. Chrome: click ⋮ → Cast, save, and share → Install page as app → Install
  2. Edge: click ⋯ → Apps → Install this site as an app → Install
  3. Right-click the new icon in the taskbar and choose Pin to taskbar if you want it there too

First time?

  1. Sign in with your @rightchoiceimprovements.com Google account when asked
  2. You'll only see the tools you've been given access to
